# fFTP

Простой FTP-сервер для Android: передать/скачать конфиги и небольшие файлы по домашней сети.

- Android 4.2+ (minSdk 17), root не нужен, без внешних библиотек (свой FTP-сервер на чистой Java), APK менее 100 КБ
- работает в фоне как foreground-сервис, в шторке иконка и кнопка «Остановить»
- настройки: галочка «включён», порт (по умолчанию 8021), имя, пароль (пусто — вход без авторизации), автозапуск при загрузке
- корневая папка — память устройства (`/sdcard`)
- команды FTP: USER/PASS, LIST/NLST, RETR (с докачкой), STOR/APPE, DELE, MKD/RMD, RNFR/RNTO, CWD/CDUP/PWD, SIZE, MDTM, PASV/EPSV/PORT, FEAT, UTF-8 имена. TLS нет (по условию — только домашняя сеть)

## Сборка APK через GitHub Actions

```
git tag v1.0.0
git push origin v1.0.0
```

Workflow `.github/workflows/build.yml` соберёт `app-release.apk` и выложит его в GitHub Release
(и в Artifacts запуска) под именем `fFTP-1.0.0.apk`. Локально собирать ничего не нужно.

### Ключ подписи (рекомендуется один раз настроить)

Если секретов нет, на каждой сборке создаётся новый временный ключ — такой APK ставится, но
**обновление поверх APK, собранного с другим ключом, не установится** (придётся удалять приложение).
Чтобы подпись была постоянной, создайте ключ один раз:

```
keytool -genkeypair -keystore fftp.jks -alias fftp -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 fftp.jks        # вывод — в секрет KEYSTORE_BASE64
```

Repository → Settings → Secrets and variables → Actions → New repository secret:

| Секрет | Значение |
|---|---|
| `KEYSTORE_BASE64` | base64 от `fftp.jks` |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `fftp` |
| `KEY_PASSWORD` | пароль ключа (если пусто — берётся пароль хранилища) |

Файл `fftp.jks` храните отдельно и не коммитьте (он в `.gitignore`).

## Использование и нюансы

- Порт ниже 1024 без root занять нельзя, поэтому допускается 1024–65535.
- Доступ к файлам: Android 6–10 спросит разрешение на память; Android 11+ откроет экран «Доступ ко всем файлам» — включите для fFTP.
- Адрес для подключения показан на главном экране (`ftp://IP:порт`). IP в уведомлении обновляется при перезапуске сервера.
- Пока сервер включён, удерживаются WakeLock и WifiLock, чтобы сервер был доступен при выключенном экране. На батарее это заметно. Предполагается что устройство стоит на зарядке.
- Автозапуск использует `BOOT_COMPLETED`. На некоторых прошивках (особенно noname-планшеты и агрессивные оболочки) этот сигнал приложению не доставляется или приложению нужно разрешение на автозапуск в настройках системы.
- После обновления приложения сервер запускается сам, если он был включён.
- `targetSdk 28` выбран намеренно: сохраняется классический доступ к памяти, и такие APK по-прежнему устанавливаются на новых Android.
